IDAT7216 产品设计 核心笔记

内容据课程 16 份课件整理。课程全名 Function Design, Aesthetics Design, Manufacturing, and Intellectual Property Law，香港大学机械工程系 Dr. Zulfiqar Ali 讲授（2025 年春季，15 周）。教材以 Ulrich & Eppinger《Product Design and Development》为主轴。主线：设计原理 → 产品开发流程 → 客户需求与规格 → 概念生成/选择/测试 → 面向制造/环境/美学设计 → 原型与制造工艺 → 知识产权。

0. 课程概览

  • 考核：CA 50%（作业 10% + Midterm 15% + 项目 25%）+ 期末考试 50%。
  • 进度：Week1-3 设计原理 → Week4-7 产品开发流程 → Week10-12 制造技术 → Week13-15 知识产权法。

1. 设计原理（Week 1-3）

  • 什么是设计：Conceiving and giving form to artifacts that solve problems——构思并赋形以解决问题的"人造物"（artifact）；设计位于艺术、商业、工程的交汇。
  • 功能 vs 形式：Function（产品做什么）对应工程设计；Form（形状/材料/美学/人机工学，即怎么做）对应工业设计。工程传统上关心 "How to Make"，今天更需要回答 "What to Make"——通过创意工程设计创新。
  • 两种设计视角：Analytical Method（分析已有问题求解决）vs Synthetic Method（无明确问题时也能综合出新方案）。
  • 设计类型/工程价值维度：产品成功评估五维——产品质量（满足客户需求？稳健可靠？）、产品成本、开发时间、开发成本、开发能力（团队未来是否更强）。
  • 产品开发三大核心职能：Marketing（机会识别/客户需求/目标价格/上市推广）、Design（定义物理形态）、Manufacturing（设计运行生产系统）；跨学科协作，周期 1~10 年。
  • 竞争维度的变迁：从制造导向（成本与质量）转向产品开发导向（特性与功能）。
  • 开发中的挑战：权衡（性能 vs 成本）、动态性（技术/偏好/竞品/宏观环境变化）、细节（螺丝 vs 卡扣可影响数百万美元经济性）、时间压力（信息不完全也要快速决策）、经济性（吸引客户 + 制造成本可控）。

2. 产品开发流程（Week 2-1）

  • 流程 = 输入到输出的步骤序列，把"概念"变为"可商业化产品"。清晰流程的价值：质量保证、协调（主计划定义各角色）、计划（里程碑）、绩效管理、持续改进。
  • Stage-Gate / 瀑布流程：阶段（Stage）+ 周期性评审门（Gate）；早期 Gate 验证市场与可制造性，后期 Gate 验证软硬件集成；每个 Gate 决定"继续/砍掉"。局限：实际项目很少按顺序走、不适合早期高度不确定性、可用版本只在最后出现。
  • 螺旋流程：迭代式 Stage-Gate，每圈结束都有"能用的部分产品"（功能不全但可用）；适合高风险、时间压缩型行业（如软件）；优点：易监控、可吸纳后期变更、降风险；缺点：成本高、流程严格，不适合低风险项目。
  • 通用产品开发流程（Ulrich & Eppinger）六阶段：
    1. Planning（使命陈述、经济分析、竞品对标）
    2. Concept Development（识别客户需求 → 建立目标规格 → 生成概念 → 选择概念 → 测试概念 → 设定最终规格）
    3. System-Level Design
    4. Detail Design
    5. Testing and Refinement
    6. Production Ramp-Up

3. 机会识别（Week 2-2）

  • 机会：新产品的想法（雏形描述、新感知的需求、新技术）；通常少于一页：标题 + 叙述 + 草图。
  • 机会三地平线：Horizon 1（现有产品的改进/变体/降本）、Horizon 2（市场或技术进入新领域）、Horizon 3（全新品类，不确定性大）。案例 FroliCat（猫玩具公司，1 年内须上市 → 选 Horizon 2）。
  • 机会锦标赛（Opportunity Tournament）：先大量生成 → 筛选过滤 → 精选；有效做法：数量大、平均质量高、质量方差大（保留"古怪想法"以博 exceptional）。
  • 识别流程六步：确立章程（Charter，目标与边界）→ 生成与感知大量机会 → 初筛 → 发展有前景的机会 → 精选 exceptional 机会 → 复盘。

4. 客户需求与产品规格（Week 4）

  • 需求类型：Direct Need（直接、易确定）、Latent Need（潜在，需深挖，常与使用/系统相关）、Constant Need（产品固有）、Variable Need（可被技术变革消除）。
  • 需求 vs 规格：需求独立于具体产品概念（不知道怎么做也能识别需求）；规格依赖于所选概念，受技术经济可行性与竞品约束。工业界同义词：customer attributes / requirements。
  • 反面教材（baddesigns.com）：洗发水与护发素瓶无法区分、灶台旋钮与炉头对应不明——形态设计必须服务可识别性与可用性。
  • 规格建立：从客户需求语句 → 指标（metric）与目标值（ideal/marginal value）→ 竞品基准测试 → 设定最终规格（技术/经济权衡后）。

5. 概念生成、选择与测试（Week 5）

  • 概念生成：在需求与目标规格确定后，先搜索外部方案（现有解决方案/专利/竞品），再内部探索；常用结构化方法（如功能分解 + 概念分类树 + 组合表），避免过早收敛。
  • 概念选择：筛选（screening，加权矩阵初排）→ 评分（scoring，多准则细化比较）；团队对齐与概念组合。
  • 概念测试：向目标客户呈现概念（草图/模型/仿真），估计购买意愿与改进方向，为最终规格与经济分析提供事实基础。
  • 美学设计（Week 6-1 专题）：同等性能/耐久/成本下，客户买"更吸引人"的——购买因素包括性能、耐久、服务、成本、舒适、环境适应性与外观；主题涵盖人机工学（Ergonomics）、情感化设计（Emotional Design，Norman）、跨文化设计、仿生设计（Biomimicry）。

6. 面向环境/制造的设计与原型（Week 6-2 / Week 10）

  • DFE（Design for Environment）：全生命周期视角（材料选择、能耗、可回收性、可拆解性）。
  • DFM（Design for Manufacturing & Assembly）：面向制造与装配的设计准则——减少零件数、标准化、防错设计、考虑公差与工艺能力；细节决策（紧固方式等）直接影响成本。
  • 原型（Prototyping）：物理/分析原型的类型与用途（学习、沟通、集成、里程碑）；快速原型（3D 打印等 Rapid Prototyping）加速迭代。
  • 制造工艺总览：成形（forming）、弯曲、冲压、真空成形、铸造、层压等常见材料加工方法；逆向工程（Reverse Engineering）作为复制/改进手段。

7. 模塑制造工艺（Week 11 专题）

  • 聚合物基础：聚合物 = 大量单体连成长链（poly=多，mer=部分）；塑料是聚合物，但聚合物不全是塑料。
  • 聚合物分类：天然聚合物（DNA/羊毛/棉）；均聚物（单一单体）vs 共聚物（两种以上单体共聚）；热塑性（可反复受热软化/冷却固化，无交联：PE、PVC、尼龙、ABS、PC、PEEK…）vs 热固性（固化后不可再塑）vs 弹性体。
  • 五大模塑工艺：
    • 注塑（Injection Molding）：熔体高压注入模具冷却定型——大批量塑料件的主流工艺；
    • 吹塑（Blow Molding）：型坯吹胀成型，用于中空件（瓶）；
    • 滚塑（Rotational Molding）：粉末受热旋转分布成中空件；
    • 传递模塑（Transfer Molding）：热固性材料经料腔注入闭合模；
    • 压缩模塑（Compression Molding）：材料直接在模腔内加热加压成型。

8. 知识产权（Week 12 专题）

  • IP 定义：头脑中的创造物——创意、发明、文学艺术作品以及商业中使用的符号、名称、图像；是重要的商业资产，可买卖/许可/授权。
  • 保护 IP 的理由：人类进步依赖创造；法律保护激励持续投入创新；促进经济增长与就业；跨国靠国际 IP 条约协调。
  • 四大类别：
    1. 专利（Patent）：保护发明；类型：Utility（实用——新且有用的方法/机器/制品/组合物及其改进）与 Design（外观设计）；保护期约 20 年；
    2. 版权（Copyright）：保护创作者对其作品的权利（文学、软件、影视等——无版权保护则影视/出版/软件产业无从谈起）；
    3. 商标（Trademark）：区分商品/服务来源的标志——文字（含人名/地名/口号）、字母数字、图形、颜色组合、三维标志、声音标记、气味标记等；作用：标明来源、保证质量、创造与维持需求、广告与形象；注册有效期 10 年、可续展；™ 为未注册、® 为已注册；描述性/含常见姓氏或地名的标记可能被拒；
    4. 商业秘密（Trade Secret）：给予竞争优势的机密信息（配方、客户名单、战略、专有设计）；适用场景：不可专利、专利期 20 年不够长（如可口可乐配方）、专利成本过高；靠保密协议、限接触、数据安全工具保护；允许对手通过逆向工程获得。
  • 一部手机中的 IP 全景：商标（Apple/iPhone/iOS）、专利（半导体电路、触屏）、外观设计（整机形态、按键布局）、商业秘密（内部工艺）。
