IDAT7215 Python 与机器学习 核心笔记

内容据课程 14 份课件整理。课程全名 Computer Programming for Product Development and Applications，由香港大学机械工程系 Dr. Zulfiqar Ali 讲授（2025 年春季，15 周）。主线：Python 基础 → 科学计算栈 → 控制系统编程 → AI/专家系统 → 机器学习 → 深度学习。

0. 课程概览

  • 考核：Continuous Assessment 50%（作业 10% + Midterm 15% + 小组项目 25%：报告 10% + 代码/演示 10% + 汇报 5%）+ 期末考试 50%。
  • 进度：Week1-2 Python 基础 → Week3-5 Python 在控制系统中的应用 → Week6-7 AI 与机器学习 → Week10-12 专家系统 → Week13-15 产品开发新技术（3D 打印/VR/AR/IoT）。
  • 参考书：Alpaydin《Introduction to Machine Learning》(MIT Press)、Ulrich & Eppinger《Product Design and Development》等。

1. Python 基础与科学计算栈（Week 1-3）

  • Python 基础：变量/类型、控制流、函数、列表与字典；面向产品开发的编程入门。
  • NumPy：ndarray 多维数组、向量化运算、广播机制；np.array/np.arange/np.linspace、矩阵运算与随机数。
  • Matplotlib：plt.plot/scatter/hist、子图布局、坐标轴标签与图例，是数据分析可视化的基础。
  • SciPy：在 NumPy 之上提供优化（optimize）、积分（integrate）、插值、统计与信号处理等模块。
  • Pandas：Series/DataFrame、read_csv、iloc/loc 索引、groupby 聚合、缺失值处理——后续机器学习的数据入口。

2. Python 在控制系统中的应用（Week 4-5）

2.1 控制系统基础

  • 基本元素：Plant（被控对象）、Feedback（反馈采样）、Error Detector（误差比较）、Controller（控制器）。
  • python-control 库：提供 MATLAB 兼容接口，核心类/函数：
    • TransferFunction / StateSpace / ZerosPolesGain：LTI 系统三种表示；
    • step / impulse / lsim：时域响应仿真；bode / freqresp：频域分析。

2.2 数学模型与方框图

  • 建模步骤：写各元件微分方程 → 拉普拉斯变换（零初条件）→ 逐个写成方块 → 组装完整方框图。
  • 例：RLC 电路 V = Ri + L·di/dt + Vc → 传递函数 Vc(s)/V(s) = (1/LC) / (s² + (R/L)s + 1/LC)。
  • 方框图化简：串联相乘、并联相加、反馈回路 G/(1+GH)；含求和点（summing point）与分支点（take-off point）的移动变换。

3. 人工智能导论（Week 6-1）

  • AI 定义：用机器模拟人类智能——问题求解、理性行动、类人行为；四大流派（思考/行动 × 类人/理性）。
  • 历史里程碑：1997 Deep Blue 胜国际象棋冠军；2011 IBM Watson 胜 Jeopardy；2016 AlphaGo（深度神经网络 + 强化学习）胜围棋冠军；2016 Google 神经机器翻译。
  • 应用：NLP（机器翻译/阅读理解/语音识别）、自动驾驶（2005 DARPA Grand Challenge）、图像生成、节能调度等。
  • AI 的局限与风险：开放域对话仍难、对抗样本（adversarial examples）、偏见、隐私（DeepFace 类人脸识别的匿名性风险）。
  • 搜索算法：状态空间搜索树（经典过河问题），是符号 AI 求解问题的基本范式。

4. 专家系统与 PyKE（Week 6-2）

  • 专家系统（ES）：Feigenbaum 1965 年于 Stanford 提出；用 AI 技术模拟某领域专家的判断与行为（医疗诊断、故障排查等）。
  • 为什么需要 ES：专家稀缺/昂贵/难即时响应，且专家知识会流失；ES 可把专家知识文档化、复制、传播。
  • 组成：
    • 知识库（Knowledge Base）：事实知识（factual）+ 经验知识（heuristic）；核心是规则库（IF-THEN 规则，可用 AND/OR 组合）。
    • 推理机（Inference Engine）：
      • 正向链（forward chaining）：数据驱动，从条件出发推向结论；
      • 反向链（backward chaining）：目标驱动，从假设结论反推所需条件。
    • 用户界面：向用户提问、根据回答继续追问直至给出诊断/建议。
  • 构建过程：知识获取 → 知识工程（建规则库）→ 原型 → 专家反馈 → 迭代精化。
  • PyKE 实践：Python 知识引擎，示例包括家族关系推理与流感/感冒判别（按 onset/fever/chills 等症状计分规则）。

5. 机器学习（Week 7，scikit-learn）

5.1 基本概念

  • ML 定义（Herbert Simon）：系统借助经验改进性能的过程；ML 是 AI 的子集，用统计方法让机器自动学习。
  • ML vs DL：深度学习受神经元启发（人工神经网络），数据依赖与硬件依赖都更强（需 GPU），ML 可在低端机器运行。
  • 数据划分：训练集/测试集典型 80/20；串行划分或随机划分（train_test_split(test_size=0.2, random_state=0)）。
  • 数据不平衡 → 过拟合：二分类样本失衡时模型只会预测多数类；需要各类样本大致均衡。
  • K 折交叉验证：分 k 份，轮流取 1 份做验证、k-1 份训练，重复 k 次取平均精度。

5.2 监督学习算法

  • 线性回归：y = mx + c，最小化误差（SSE）；斜率 m = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²；拟合优度 R²（决定系数，越接近 1 越好）。
  • 回归指标：MAE、MSE、RMSE（0.2~0.5 视为合理，越小越好）。
  • 逻辑回归：分类算法，sigmoid S 曲线把输出压到 [0,1]，以 0.5 为阈值判定类别。
  • 混淆矩阵与指标：
    • Accuracy = (TP+TN)/(P+N)——不平衡数据下会失真（例：90 健康/10 患病全预测为健康的"90% 准确率"模型毫无价值）；
    • Precision = TP/(TP+FP)；Recall = TP/(TP+FN)；F1 = 2PR/(P+R)（调和平均，优于单看 accuracy）。
  • 决策树：按条件的树状决策，可解释性强；单棵大树易过拟合。
  • 随机森林：多棵树 + bagging 集成，纠正决策树过拟合，更准更稳（课件实验：Kyphosis 数据集上决策树 0.60 → 随机森林 0.76）。
  • 朴素贝叶斯：基于贝叶斯定理 P(H|E) = P(E|H)·P(H)/P(E)，"朴素"假设特征条件独立；三型：Gaussian（连续正态特征）/ Multinomial（离散计数）/ Bernoulli（0-1 特征）；应用：垃圾邮件过滤、新闻分类、人脸识别。
  • KNN：存全部样本，按最近 K 个邻居投票分类；K 取值影响结果（K=3 归 Cat、K=7 归 Dog 的直观例子）。
  • SVM：找最大间隔超平面分类；非线性数据用核函数（Linear / Polynomial / RBF / Sigmoid）映射到高维再分；应用：人脸检测、文本分类、生物信息学。

5.3 学习类型总览

  • 监督：分类（图像分类、欺诈检测）+ 回归（销量/天气预报）。
  • 无监督：聚类（推荐、客户分群）+ 降维（可视化、压缩、特征提取）。
  • 强化：agent 与环境交互试错拿奖励（Q-Learning、SARSA）；应用：自动驾驶、游戏 AI、机器人导航。

6. 无监督学习（Week 10）

  • 聚类：组内相似度高、组间相似度低；无需标签即可发现隐藏模式。
  • 聚类三型：Exclusive（K-means，一个对象只属一个簇）、Overlapping（Fuzzy/C-means，可属多簇并带隶属度）、Hierarchical（树状父子结构）。
  • K-means 算法：随机初始化 k 个中心 → 每点归入最近中心 → 用簇内均值更新中心 → 重复直至收敛（类似高斯混合的 EM）。
    • 例：4 种药物按 (weight, pH) 分 K=2 组的手算迭代；肘部法选 K：对每个 k 算 SSE = Σ dist(x, ci)²，取 SSE 骤降处（heuristic，可能无肘或多肘）。
    • 优缺点：简单快速、收敛到局部最优；但需预设 k、对初始中心和离群点敏感、只认球形簇。
  • 层次聚类：每点自成一簇 → 反复合并最近的两簇 → 树状图（Dendrogram）记录合并过程，到只剩一簇为止。

7. 深度学习（Week 11，特邀 Nauman Munir 博士, PolyU CAiRS）

  • 为何现在爆发：大数据集 + GPU 算力 + 算法/结构创新 + 迁移学习 + 框架成熟。
  • 基本单元：
    • TLU/感知机（Rosenblatt 1957）：output = φ(XW + b)，全连接（dense）层；
    • 多层感知机 = 全连接网络（FNN）。
  • 激活函数：Sigmoid、tanh、ReLU（max(0,x)）、Heaviside。
  • 损失函数：
    • 分类：交叉熵 L = -Σ yi·log(ŷi)；
    • 回归：MSE（重罚大误差、对离群敏感）、MAE（对离群稳健、零点不可导）、Huber（小误差二次、大误差线性，兼顾两者）。
  • 反向传播：前向计算损失，链式法则逐层求 ∂L/∂w、∂L/∂b，梯度下降最小化损失。
  • 经典架构：FNN、CNN（卷积）、FCN、RNN（循环）、GAN（生成对抗）；TensorFlow 实现示例。
