微系统 (MEMS) 核心笔记

内容据课程 4 章课件整理。课程全名 Microsystems for Energy, Biomedical and Consumer Electronics Applications (MECH6046)，香港大学 Dr. Dong-Myeong Shin 讲授。考核含小组项目（40 分，微系统/微加工前沿技术选题汇报，教师 60% + 同组 20% + 他组 20%）。主线：微系统中的力学 → 静电感知与驱动 → 压阻/压电效应 → 微流控与能源。

0. 微系统概述

  • 微系统构成：微传感器（把能量从其他域转换到电域）+ 微执行器 + 信号处理电路。
  • 传感器品质因数（Figure of Merit）：检测限、灵敏度、线性度、动态范围、鲁棒性；实现同一感知需求有多条技术路径，须权衡性能/成本/简单性。

1. 微传感器（Ch01）

  • 声表面波传感器（SAW）：两套叉指换能器 IDT + 压电层——输入 AC 信号在压电膜上激发表面形变波传播到检测端再转回电信号；传播波性质（幅值/频率/相位）随介质质量、粘弹性、湿度、化学、温度变化；应用：触摸屏、移动设备滤波器。
  • 生物传感器：样品中生物分子（抗原）与敏感元件（抗体）结合改变元件性质，可用化学/光学/热/谐振/电化学/ISFET 等方式检测。
  • 化学传感器四类：化学电阻式（chemiresistor）、化学电容式、化学机械式（某些聚合物遇化学品/湿气变形）、电化学式（气体在工作电极氧化/还原产生电流）。
  • 光学传感器：基于光子-电子相互作用；选型依据：探测波长（半导体带隙：Si 1901100nm、Ge 4001700、InGaAs 800~2600、PbS 至 3500）、量子效率（GaAs 高于 Si）、响应时间、噪声、成本；四类器件含光电二极管、光电晶体管。
  • 压力传感器（历史最久的 MEMS 产品）：薄膜（diaphragm）受压变形 → 转换单元变为电信号：
    • 压阻式：掺杂硅（B/As/P 注入）微电阻构成惠斯通电桥 R1-R4，输出 V0 = Vin(Δ12−Δ34)/(2+Δ12+Δ34)；紧凑、线性好、温敏、成本较高；
    • 电容式：平板电容 C = εrε0A/d（ε0=8.85 pF/m），间隙 d 随膜片变形改变；体积较大、非线性，但温度不敏感。

2. 静电感知与驱动（Ch02）

  • 基础公式（忽略边缘电场的一阶分析）：库仑力 F = q·q′/(4πε0r²)；平板电容 C = εrε0WL/d；Q = CV、E = V/d；真实器件设计需有限元仿真计及边缘场。
  • 静电驱动：对极板加电压产生静电力，由储能 U = −½εrε0(WL/d)V² 对坐标求偏导得三方向力（间隙向 Fd = −½CdV²，力与间隙平方成反比；负号表示恢复完全重叠的倾向）。
  • 电容驱动的优缺点：几乎通用的感知/驱动方式、无需特殊材料、电压驱动功耗低、响应快；但力与距离反向缩放（大力需小间距）、非线性、易被颗粒卡死、易因分子间作用力粘连（sticking）、牺牲层去除工艺难。
  • 典型配置：平行板（面外运动）与梳齿驱动（comb drive / IDT，面内运动，分横向与纵向两种）。
  • 应用实例：电容加速度计、密封腔压力计、差分电容流量计、电容触觉传感器、变形镜阵列（自适应光学：间谍卫星、机载激光）与数字微镜像素（DMD 投影）。

3. 压阻与压电效应（Ch03）

  • 压阻效应：固体因应变/变形电阻变化 R = ρl/A，两个来源：① 几何尺寸变化（金属应变计原理）② 电阻率 ρ 随应变变化（半导体主导，用单晶硅压阻系数矩阵描述各向异性关系）。
  • 传感器设计要点：微梁/膜片上压阻应布置在最大应力点（对比好/差设计）；膜片受均匀压力的变形与应变解析；惠斯通桥读出。
  • 压电效应：晶体受应力产生极化（P、电位移 D），各向异性材料用压电系数矩阵 dij 描述；逆压电效应：加电场产生应变（驱动器基础）；发现历史与潜艇声呐军事应用驱动了早期发展。
  • 材料：PZT（锆钛酸铅，压电系数大）、ZnO 等。
  • 应用：压电悬臂执行器、声波传感器（SAW 的 IDT 换能器）、喷墨打印头（压电腔按所需电场设计驱动墨滴）。

4. 微流控与能源（Ch04）

  • 微流控（Microfluidics）：1980 年代兴起；含流体部件至少一维 <1 mm；类比"让水像电子在集成电路里一样流动"。
  • 芯片实验室（Lab-on-a-chip / μTAS）：单片集成电子/流体/机械/光学/磁学等多种实验室功能；动机：MEMS 的便携、批量低成本、高性能 + 纳升级样本、易操作、快速出结果、POCT 床旁/现场检测。
  • 应用实例：快速 DNA 检测芯片（PCR 扩增集成）、器官芯片（Harvard 肺-on-chip、MIT 肾-on-chip 用于药物筛选）、仿生（人体血管/树木导水的天然微流道）。
  • 流体力学基础：密度 ρ、黏度 μ（牛顿黏性定律 τ ∝ du/dy，水 1.7 cp）；雷诺数 Re = ρVL/μ（特征长度 L：微通道取直径）——微尺度下 Re 极小 → 层流主导（无湍流混合，依赖扩散）。
  • 制造：表面/体微加工、键合；材料：硅、玻璃、PDMS（聚二甲基硅氧烷）——1:10 基料/催化剂真空加热数小时固化；工艺：光刻+刻蚀做硬质模具 → 浇注 PDMS → 真空脱泡 + 加热固化 → 脱模。
    • PDMS 优点：微米特征复制成型、快且便宜、柔而强、透明（利于显微观察）、透气（低压即可排出网络内空气）、可做多层器件；
    • 缺点：透水蒸气（样品失水）、疏水（不利于细胞培养）、不耐有机溶剂。
  • 关键部件：微通道/微腔（nm~mm 截面，永久或可逆键合；埋藏通道可用激光熔融+氧化密封）、微阀（低泄漏、可靠简单、易造）、微泵（含三相蠕动泵）；尺寸排阻分离：微柱阵列（bump array，Science 2004）按粒径连续分选。
