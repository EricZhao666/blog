CAPD 计算机辅助产品设计 核心笔记

内容据课程 14 份课件整理。课程全名 Computer Aided Product Development (MECH6034)，香港大学 Dr. Y.H. Chen 讲授。教材主线：产品开发方法论（QFD / DFMEA / TRIZ）+ CAD/CAM/逆向工程 + 3D 打印。考核：Assignment 20%（3D 打印）+ 考试 80%（5 题选 4）。

0. 课程总览：计算机能做什么、不能做什么

  • CAPD ≠ 自动化产品开发：计算机能辅助"草绘 → 建模 → 渲染 → 原型 → 设计分析 → 详细设计 → 验证"的大量迭代；但概念设计（创意）无法自动化——Creativity & Innovation can not be automated，这正是结构化方法论（TRIZ/QFD）存在的意义。
  • 生成式设计（Generative Design）：AI 算法按性能要求/工艺/材料生成并评估多个设计替代方案；目前主要支持几何设计与优化。
  • 并行工程（Concurrent Engineering）：市场调研、预算、工程研究、设计（DFX）、制造、服务、销售、供应商早期并行介入——设计决策越晚改，代价越高（成本影响随开发阶段指数上升）；反例：Airbus A380 好设计但无市场。
  • DFX（Design For X）：DFM 可制造性、DFA 装配、DFS 维修性、DFR 可靠性/回收、DFE 环境、DFC 成本……
  • 产品开发：愿景使命 → 商业分析（可行性/盈利能力）→ 工程设计 → 设计验证 → 制造计划 → 营销计划 → 生命周期末端服务；产品开发范围 > 产品设计。

1. 结构化方法论工具箱（按阶段）

  • Phase 1 产品研究：QFD（质量功能展开）、设计评审、风险-机会分析（机会/风险比 ≥ 1）、SWOT 分析。
  • Phase 2 概念生成：虚拟原型、触觉建模、决策矩阵、对标（Benchmarking）、头脑风暴（TRIZ）、逆向工程。
  • Phase 3 设计与工程分析：CAD/CAM、原型、3D 打印、DFMEA。
  • Phase 4 产品实现：过程规划、过程控制计划、PFMEA（过程失效模式分析）。

1.1 QFD 质量功能展开

  • 作用：把"客户行话"转成技术指标；建立客户需求与产品设计的理性映射；需要跨部门团队输入。
  • 历史：1972 三菱重工神户造船厂起源 → 1976 丰田引入汽车业 → 1984 后进入美国 → 1990 年代服务业跟进。
  • 四级展开：QFD1 产品规划（设计要求）→ QFD2 零件展开（零件特征）→ QFD3 过程规划（工序操作）→ QFD4 生产规划。
  • 质量屋（House of Quality）8 个房间（常用 1-5）：
    • Room 1 客户之声（访谈+相对重要性，改写模糊表述）；
    • Room 2 工程/技术要求（精确表述：功能/重量尺寸/功率效率/成本/安装服务/报废/外观舒适/运输存储）；
    • Room 3 客户需求与技术要求相关性矩阵；
    • Room 4 客户对现有品牌（取前三）感知排名；Room 5 技术属性竞品排名；
    • 其余：技术相关性屋顶、目标值等。

1.2 DFMEA 设计失效模式与影响分析

  • 目的：识别并评估潜在失效模式与原因 → 找出消除/降低措施 → 文档化；重在预防而非检测；详细设计之后、量产之前使用。
  • 要素：失效模式（如车门密封不足导致噪音）→ 失效影响（司机不满、分心、销量下降）→ 失效原因（密封件不足/材料错误）。
  • RPN 风险优先数 = Sev × Occ × Det（1~1000，越高越优先整改）：
    • Sev 严重度：仅看对客户的影响（1 无感 → 9-10 安全/法规不符）；只能靠改产品设计降低；
    • Occ 发生度：寿命期内失效概率（1 → 1/1,500,000；9-10 → 1/2~1/3）；
    • Det 探测度：现行验证流程在设计放行前发现弱点的能力（1-2 几乎必能发现 → 10 无法发现）；只能靠改验证流程降低。
  • 案例：高田（Takata）安全气囊充气力过大——潜在失效可能终身不发生但仍须管控。
  • FMEA 分型：系统（概念）/ 设计（零件）/ 过程 / 供应商。

1.3 TRIZ 发明问题解决理论

  • 起源：Altshuller 1946 年起分析全球专利中的发明模式；本质是"引导式横向思维"。
  • 两大基本原理：① 你的问题（或相似问题）早已有人解决过——创造力是找到该解法原理并适配当前问题；② 解决问题 = 解决矛盾。
  • 三大基本认识：问题与解法跨行业重复出现（按矛盾分类可预测创造性解法）；技术进化模式跨行业重复；创新常借用本领域之外的科学效应。
  • 矛盾示例：安全气囊展开越快保护越好，但越快越易伤及离位乘员；垃圾邮件过滤越彻底，越可能误杀想要的邮件。
  • 解题流程：具体问题 → 用 39 个工程参数表述（重量/长度/面积/体积/速度/力/应力/形状/稳定性/强度/温度/功率/能量损失/物质损失/信息损失/时间损失/可靠性/测量精度/制造精度/有害因素/可制造性等，区分运动物体与静止物体两套）→ 查矛盾矩阵 → 得 40 条发明原理（分割、抽取、非对称、合并、嵌套、预操作、变害为利……）→ 从一般解到具体解。

2. CAD/CAM 与逆向工程

  • 模型类型演进：线框（wireframe，只有顶点+边，有歧义）→ 表面模型 → 实体（volume）模型；波音 777 模型数万零件、3.5 亿三角形可视化。
  • 知名软件：AutoCAD、SolidWorks、UG、Pro/E、CATIA、ANSYS、Delcam、Mastercam（及电气/建筑/医疗牙科专用 CAD）。
  • 设计表示链：规格说明 → 功能模型（图/流程）→ 轴测与正交草图 → CAD 模型（零件/装配/动画/FEA/BOM）→ 技术模型（尺寸公差/材料/约束/制造数据，用于生产）。
  • CAD 模型应用：装配仿真、质量评估、BOM、运动动画、转动惯量、变形与应力（多物理场：气动/水动力/热）等下游评估。
  • 逆向工程：扫描/数字化已有实物反求 CAD 模型（配合数字化仪、MRI/CT 医学影像建模）。

3. 3D 打印 / 增材制造

  • 本质：AM = Layered Manufacturing 分层制造。
  • 五步流程：① 获取几何数据（CAD 建模或扫描/MRI/CT）② 转 STL（表面三角化，每个三角形带外指单位法向量，便于切片）③ 切片成层（层厚决定精度/打印时间/表面质量；层内再离散为像素级路径）④ 选择工艺逐层堆积 ⑤ 后处理（去支撑、打磨抛光）。
  • STL 细节：三角形按右手系逆时针（从外看）列出顶点；弦差（chordal error）衡量近似误差；三角化应最大化最小角（避免瘦长三角形，利于数值稳定与 FEA）；n 边形可拆 n-2 个三角形——三角形是 2D 最简形态（类比数字图像的像素）。
  • 四大要素：输入（STL/IGES/CLI、多材料/梯度/颜色数据）、材料（粉末/液体/薄片/颗粒/丝材；尼龙/ABS/蜡/陶瓷/金属）、成形方法（光固化、切割粘接、熔化凝固、烧结、粘结）、应用（设计/制造/工装、生物医疗、食品、建筑）。
  • 主要工艺：
    • FDM 熔融沉积（Stratasys 1988，专利 2009 到期引爆桌面机）：XY 机械臂挤出热塑丝材，Z 向逐层；双喷嘴（成型材 + 支撑材）；
      • PLA vs ABS：PLA 玉米/甘蔗基可降解、打印 190-220℃ 无需热床、无味无毒、硬而脆（适合外观原型）；ABS 石油基、打印 230-250℃ 需热床、延性好耐用（适合最终用途件）；
    • SLS 选区激光烧结（DTM 1990）：CO₂ 激光 30-70W 将粉末（10μm，尼龙/PC/陶瓷）加热至熔点下方烧结；未烧结粉末即天然支撑——无需预设支撑、可做活动装配件；多孔（密度 98%99% 计量）、有收缩翘曲；粉料可回收但粉尘大；
    • SLM/DMLS 激光熔化：更高功率 200-400W 完全熔化金属粉（如 316L 不锈钢，粒径 17μm），致密度高于 SLS；慢且贵、公差与表面有限，但可制造高密度标准金属件。
  • 应用领域：快速原型、直接终端件制造、工装夹具、生物医疗（CT/MRI 个性化建模）等。
